# Сортировка задачи — лист Карты доверия

> Заполни перед любой нетривиальной задачей для ИИ. Занимает 2 минуты.

**Задача:** _одно предложение_

## 1. Цена ошибки

Если результат неверен и этого никто не заметит, что будет?

- [ ] Ничего страшного / легко переделать → **Низкая**
- [ ] Деньги, репутация, юридические последствия, безопасность, клиенты или ошибки, которые всплывут нескоро → **Высокая**

## 2. Лёгкость проверки

Как будет подтверждена правильность результата?

- [ ] Тесты, контрольные суммы, эталонный пример, быстрый визуальный просмотр или короткое чтение знающим человеком → **Легко**
- [ ] Нужна глубокая экспертиза, долгое исследование, или покажет только время → **Трудно**

## 3. Квадрант

| | Легко проверить | Трудно проверить |
|---|---|---|
| **Ошибка дешёвая** | 🟢 Делегируй | 🔵 Исследуй |
| **Ошибка дорогая** | 🟡 Делегируй + проверяй | 🔴 Советуйся |

**Итог:** 🟢 / 🟡 / 🔵 / 🔴

## 4. Можно ли перевести в лучший квадрант?

- [ ] Разбить на мелкие части, каждую из которых легко проверить
- [ ] Требовать источник/ссылку для каждого фактического утверждения
- [ ] Заранее подготовить тесты, контрольные суммы или эталонные примеры
- [ ] Запросить структурированный результат, который проверяется автоматически

**После изменений:** 🟢 / 🟡 / 🔵 / 🔴

## 5. Режим работы

| Квадрант | Режим | Проход «Сломай» | Кто принимает |
|---|---|---|---|
| 🟢 | ИИ делает целиком | Выборочно | Любой |
| 🟡 | ИИ делает, всегда проверяется | **Обязателен** | Владелец после проверки |
| 🔵 | ИИ предлагает варианты | По желанию | Владелец выбирает |
| 🔴 | ИИ только советует | **Обязателен** для любого используемого анализа ИИ | Решает и отвечает человек |
